# JavaScript Iterators some() Method

Applying the `some()` method to a JavaScript Iterator.  The some() method returns true if at least one element satisfies a test function.  For example, if the text contains vowels (a, e, I, o or u).

## UX

**Getting Started**

In the text field, enter text (e.g. Hello World).  You will see the text entered as well as contains vowels information (Yes or No).  For example, Hello World contains vowels, because e and o are vowels.

**User Stories**

- As a user, I expect to see the text I have entered
- As a user, I need to know if the text contains vowels (Yes or No)
- As a user, if I click on the `Clear` button, I expect the information to be cleared.

## Features

Allows the user to enter text in order to know if vowels are contained.

## Technologies

Uses HTML5, CSS3, JavaScript, Bootstrap 5.3.2 and jQuery 4.0.0.
